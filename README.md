# 逃出研究室（Escape the Lab）

以 three.js 製作的第一人稱恐怖解謎遊戲，單一 `index.html` 即可執行，單局約 10–15 分鐘。完整規格見 [SDD/SDD.md](SDD/SDD.md)（v1.9）。

網站連結：[逃出研究室](https://lxl921118.github.io/Taica/)

## 執行

```bash
npx serve .          # 或 python -m http.server
```

用瀏覽器開啟顯示的網址。不能直接雙擊開檔（`file://` 無法載入 ES Module），且需要網路載入 three.js。網址加 `?debug` 會顯示 FPS 與 draw call。

## 遊戲流程

1. **第一章 封鎖的研究室**：全黑的研究室中，滑鼠游標就是手電筒光圈。找齊紅、藍、黃三把鑰匙（8 個藏匙點隨機抽 3 個），打開前門。
2. **第二章 異常走廊**：無限重複的研究大樓走廊。**有異常就回頭，沒異常就往前**，連續答對 8 次後從大樓出口逃出；答錯計數歸 0。

## 影子

- 被手電筒照到時完全靜止；連續照 3 秒會瞬移到視線外。沒被照到就朝玩家移動，會繞過桌椅。
- 速度 0.6 m/s 起，隨鑰匙數與時間加快，上限 2.0 m/s；距離 < 1.2 m 即被抓。
- 看不到它時會換姿勢；靠近時有心跳、呼吸低語與拖行聲（依方向左右定位）。
- 第一章畫面沒有任何預兆，被抓瞬間顯示滿版恐怖圖片；第二章有手電筒閃爍、紅色暗角，被抓前影子會撲向鏡頭。

## 異常（22 種，依計數解鎖難度）

| 難度 | 解鎖計數 | 異常 |
| ---- | -------- | ---- |
| 明顯 | 0 起 | 多一扇門、燈全滅、影子站在走廊上、窗外是白天、飲水機漏紅水 |
| 中等 | 3 起 | 海報人物轉向、時鐘倒轉、滅火器倒立、多一組腳步聲、海報字變「回頭」、白板寫著來過幾次、飲水機只剩冷或熱、監視器照牆 |
| 細微 | 6 起 | 門牌順序錯亂、走廊變長、天花板變低、窗上手印、進度牌數字錯、C# 程式輸出錯、學生證變中台科大、學生證系所錯、系主任不姓姜 |

每次進入第二章的第一輪必為正常；之後每輪 60% 機率出現 1 種異常，抽完一輪才重複。

## 操作

| 按鍵 | 第一章 | 第二章 |
| ---- | ------ | ------ |
| WASD／Shift | 移動／快走 | 移動／快走 |
| 滑鼠 | 移動光圈，視角跟著轉；按住左鍵集光 | 轉動視角 |
| E | 拾取鑰匙、開門 | — |
| F | — | 開關手電筒 |
| Esc | 暫停 | 暫停 |
| H | 展示提示（標示鑰匙） | 展示提示（顯示本輪答案）；`[` `]` 指定下一輪異常、`0` 取消 |

標題畫面的「直接進入走廊」可跳過第一章（不記錄最佳時間）。

## 技術規格

- 單一 `index.html`（HTML + CSS + JS）；three.js r160 由 jsDelivr 以 importmap 載入；跳嚇圖片以 base64 內嵌。
- 場景、貼圖（Canvas）、音效（Web Audio）全部由程式產生；`localStorage` 只存最佳通關時間。
- 支援 Chrome／Edge 120+、Firefox 120+、Safari 17+；目標一般筆電內顯 ≥ 55 FPS、draw call < 150。
